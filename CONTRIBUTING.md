# Contributing

Open an issue describing the production workflow, expected measurement, and reproducible evidence. Use original/synthetic examples or artwork you have permission to share. Never upload client files or secrets.

Keep image operations independent of HTTP/database concerns. Add regression coverage for meaningful algorithm changes and preserve uncertainty/unavailable states. New AI explanations must remain separate from deterministic scoring. Run backend tests, the real-service Playwright suite, production build, dependency audits and the benchmark. Report regressions and evaluation scope rather than optimizing only aggregate accuracy.

Python 3.14 and Node 24 are the validated targets. Preserve the local no-key path and OFL license files. Contributions are under AGPL-3.0-or-later.
